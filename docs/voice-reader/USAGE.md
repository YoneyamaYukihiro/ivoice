## 1. このアプリで何ができるか

- 貼り付けた文章を **ブラウザ内蔵の音声合成** で読み上げます
- 固有名詞（社内用語・人名）の **読み間違いを辞書で直せます**
- 朝会の台本のような **再利用する文章をテンプレ保存** できます
- `{date}` `{presenter}` のような **プレースホルダ** で毎日変わる値を差し替えられます
- `# 見出し` で書いた文章を **セクションごとに間を取って読み上げ** できます（司会モード）
- 名前には自動で「さん」「くん」「様」を付けられます（自分は付けない設定も可）

### 何ができないか
- 録音 / mp3 出力（ブラウザ内蔵 TTS の制約）
- Teams 会議に bot として参加させる
- 多デバイス間のデータ同期（localStorage のため）

## 2. 起動と初期準備

### 初回のみ

1. リポジトリディレクトリで `npm install` を実行（依存ライブラリのインストール、1〜2 分）

### 毎回（バッチで起動するのが楽）

プロジェクト直下に **`start.bat`** がある。これをダブルクリックすれば自動で `cd` + `npm run dev` を実行する。

タスクバーやデスクトップにショートカットを置いておくと、朝に 1 クリックで起動できる。

### 毎回（コマンドで起動）

PowerShell でプロジェクトディレクトリに **必ず移動してから** 起動する。`npm` は今いるディレクトリの `package.json` を探すため、別の場所だと `ENOENT: package.json not found` で失敗する。

```powershell
cd c:\Users\5001699\source\repos\YoneyamaYukihiro\ivoice
npm run dev
```

出力に以下が出たら成功：

```
- Local:        http://localhost:3000
✓ Ready in X秒
```

ブラウザ（**Edge または Chrome 最新版**）で http://localhost:3000/reader を開く。

### 終了

- 起動中のターミナルで **Ctrl + C** で dev サーバを停止
- ターミナルを閉じてしまった場合は、プロジェクト直下の **`stop.bat`** をダブルクリック（全 Node プロセスを強制終了）

### ポート競合・うまく起動しない場合の再起動手順

`npm run dev` の出力に：

```
⚠ Port 3000 is in use, trying 3001 instead.
⚠ Port 3001 is in use, trying 3002 instead.
- Local:        http://localhost:3002
```

と出た場合は、**前回の dev サーバプロセスがまだ残っている** ことが原因。3002 でもアクセスは可能だが、3000 で動かしたい場合は以下でクリーンに再起動：

```powershell
# 1. 動いている Node プロセスを確認
tasklist /FI "IMAGENAME eq node.exe"

# 2. すべての Node プロセスを終了
taskkill /F /IM node.exe

# 3. プロジェクトディレクトリへ
cd c:\Users\5001699\source\repos\YoneyamaYukihiro\ivoice

# 4. 起動
npm run dev
```

**注意**: `taskkill /F /IM node.exe` はマシン上のすべての Node.js プロセスを強制終了する。他に Node を使うアプリ（VS Code 拡張など）があればそれも巻き込まれるので注意。

### URL でハマったら

| URL | 結果 |
|-----|------|
| `http://localhost:3000` | ivoice 本体ページ（未使用想定） |
| `http://localhost:3000/reader` | ✅ AI-Voice司会くん |
| `http://localhost:3000/readers` | ❌ 404（末尾の s が余分） |
| `http://localhost:3002/reader` | ✅（ポート競合で 3002 に逃げた場合） |

`/reader` の `r` は小文字、末尾の `/` はあってもなくても可、`s` は付けない。

## 3. 基本：貼って読み上げる

### ステップ

1. 「読み上げるテキスト」の枠に文章を貼る、または入力
2. 「**通常読み上げ**」ボタンを押す
3. ブラウザのスピーカーから声が再生される

### 再生コントロール

| ボタン | 動作 |
|--------|------|
| 一時停止 | 一時的に止める |
| 再開 | 続きから再生 |
| 停止 | 完全に止める |

### 声を変える

「声」のプルダウンで選択。Edge なら `Microsoft Nanami Online (Natural)` などが自然です。

### 話速を変える

「話速」スライダー（0.5x〜1.5x）。デフォルトは 1.1x。

**注意**: 再生中に話速を変えても **その utterance には反映されません**。一度止めて再度押し直してください（司会モードはセクション切り替えのタイミングで反映されます）。

## 4. メンバーを登録する

「水口」と書かれたテキストを「みずぐち さん」と読ませたい、というような **氏名 → 読み + 敬称** の登録です。

### 登録手順

1. 画面右上の「**メンバー (N)**」リンクをクリック
2. 上部のフォームで以下を入力：
   - **氏名**: テキストに出てくる表記（例: `水口`）
   - **よみがな**: 実際の読み（例: `みずぐち`）
   - **敬称**: さん／くん／様／なし から選択
3. 「追加」ボタンをクリック
4. 下のテーブルに行が追加される

### 複数まとめて登録（CSV 一括）

毎日同じメンバーを読むなら、最初に一括登録するのがラクです。

1. 「メンバーを一括追加（CSV）」をクリックして展開
2. テキストエリアに 1 行 1 名で入力：
   ```
   水口,みずぐち
   浅川,あさかわ
   神澤,かみざわ,さん
   里見,さとみ,くん
   ```
   形式: `氏名,よみがな,敬称`（敬称は省略可、デフォルト さん）
3. 「一括追加」ボタンをクリック

### 「自分」をマークする

自分の名前は呼び捨てで読みたい場合：

1. テーブルの「**自分**」列のチェックボックスをクリック
2. その行が水色になり、敬称列が「（敬称なし）」になる
3. 同時に 1 人だけマーク可能（別の人をマークすると自動切替）

これで、自分の名前が出てきたとき：
- 「米山さん」と書かれていても **「よねやま」** と読まれる
- 「米山」のみの場合も **「よねやま」** と読まれる

### 編集する

テーブルの「氏名」「よみがな」セルは **直接編集できます**（クリックして入力）。敬称はドロップダウンで変更可能。変更は即 localStorage に保存されます。

### バックアップ・移行

ページ上部の「**エクスポート**」ボタンで現在のメンバー一覧を JSON ファイルとしてダウンロード（`voice-reader-members-YYYY-MM-DD.json`）。「**インポート**」で JSON を読み込み（既存件数があれば確認後に上書き）。別 PC や別ブラウザに引き継ぐとき・バックアップ用に。

## 5. 固有名詞辞書を登録する

人名以外の **社内用語・略語** などを登録します。

### 例

| 表記 | よみがな |
|------|---------|
| PCDT | ピーシーディーティー |
| SPO | エスピーオー |
| 富士見 | ふじみ |

### 登録手順

1. 画面右上の「**辞書 (N)**」リンクをクリック
2. フォームに「表記」「よみがな」を入力 → 「追加」
3. テーブルに行追加

### メンバーとの違い

| | メンバー | 辞書 |
|-|---------|------|
| 用途 | 人名 | 一般語・略語 |
| 敬称付与 | あり（自動） | なし |
| 既存敬称の検出 | あり（「水口さん」→「みずぐちさん」重複しない） | なし |

人名は必ずメンバー側に登録すること。辞書側に入れると敬称が付かない。

### 編集する

テーブルの「表記」「よみがな」セルは **直接編集できます**（クリックして入力）。変更は即 localStorage に保存されます。

### バックアップ・移行

メンバーと同様、「**エクスポート**」「**インポート**」ボタンで JSON ファイル（`voice-reader-dictionary-YYYY-MM-DD.json`）として持ち出し / 取り込みできます。

## 6. 台本テンプレを保存・呼び出す

朝会など定例で使う文章を、名前を付けて localStorage に保存できます。

### 保存

1. textarea に台本を作る
2. 「**現在を保存**」ボタンをクリック
3. 名前入力プロンプトが出る → 例: `朝会` と入力 → OK
4. 上部の「保存した台本」プルダウンに `朝会` が出る

### 呼び出し

1. プルダウンから保存名を選ぶ
2. textarea に内容が展開される

### 上書き保存

1. 既存テンプレを呼び出して編集
2. 「**現在を保存**」をクリック
3. 同じ名前で OK → 黙って上書き（同名既存に対しては名前付け時のみ確認）

### 削除

呼び出し中のテンプレに対して「**削除**」ボタン（プルダウン横）が出ます。

### バックアップ・移行

「保存した台本」行の下に「**エクスポート**」「**インポート**」ボタンを配置。`voice-reader-templates-YYYY-MM-DD.json` 形式で持ち出し / 取り込みできます。

### 注意

- **編集中に別テンプレを呼び出すと現在の内容は失われます**（明示警告なし）
- 保存は **このブラウザのみ**。別 PC やブラウザには引き継がれません

## 7. プレースホルダで毎日値を差し替える

テンプレ本文に `{date}` や `{presenter}` のような **目印** を入れておくと、再生前に値を差し替えられます。

### 仕組み

```
テンプレ本文: 本日の担当は {presenter} です。
                 ↓ プレースホルダパネルで「水口」選択
最終テキスト: 本日の担当は 水口 です。
```

### プレースホルダの種類

#### 1. 組み込み（自動入力）

| key | 値 | 例 |
|-----|---|----|
| `{date}` | 月日 | 6月5日 |
| `{today}` | 同上 | 6月5日 |
| `{date_full}` | 年月日 | 2026年6月5日 |
| `{weekday}` | 曜日 | 金曜日 |
| `{time}` | 時刻 | 14時30分 |

書くだけで自動で値が入ります（必要なら上書き編集可）。

#### 2. 人物（`{presenter}` `{担当者}`）

メンバーが登録されていれば **ドロップダウン** が出て、登録メンバーから選択。
メンバー未登録なら **テキスト入力**。

選んだ値はそのまま挿入され、敬称は付きません（人物プレースホルダは「敬称を付けない」が仕様）。
台本側で `{presenter}さん` と書けばさん付きで読まれます。

さらに、**選ばれた人物の氏名は本文中の自由文（`{本日の予定}` 内など）に出てきても敬称が付きません**。「今日の登板者は呼び捨て」というのを朝会の台本ロジックとして自動でやってくれます。

#### 3. 複数行（textarea）

key 名に「予定」「本文」「内容」「一言」「コメント」「schedule」「content」「comment」を含むと **複数行 textarea** で表示。

例: `{本日の予定}` `{明日の予定}` `{一人一言}` `{コメント}`

チャット出力（Copilot / ChatGPT 等）をそのまま貼れます。貼った内容にはメンバー置換も辞書も適用されます。

ラベル右に **「チャットを整形」** と **「クリア」** ボタンを配置。整形は太字記号・箇条書きを除去し、空行で囲まれたカテゴリ行を `# 見出し` に変換します。クリアは中身を空に。

#### 4. その他

自由なテキスト入力（単一行）。

### 注意

- 未入力のプレースホルダは **無音で飛ばされます**（v0.2.0 以降、再生はブロックされません）
- 本文が完全に空になったセクションは **丸ごとスキップ** されます
- プレースホルダ値は **画面リロードで消えます**（毎日入れ直す前提）

## 8. 司会モードで間を取って読む

`# 見出し` で書かれた文章は、セクションごとに別々に読まれ、間に **間（無音）** を挟みます。

### 書き方

```
# オープニング
おはようございます。本日の朝会を始めます。

# 進捗共有
順番に共有してください。

# クロージング
本日もよろしくお願いします。
```

`# ` の後にタイトル（半角 `#` でも全角 `＃` でも可、後ろの空白は省略可）。

### 起動

1. テキストにセクションを書く
2. 「セクション一覧」が下に表示される（N セクション認識）
3. 「**司会モードで再生 (N セクション)**」ボタンが出る
4. クリックで上から順に再生

### セクション間の動作

- セクション終了後、設定秒数（デフォルト 1 秒）の無音
- 待機中は「**次のセクションへ →**」ボタンで早送り可能
- 「**停止**」で全中断

### 設定

| 項目 | デフォルト | 範囲 |
|------|---------|------|
| セクション間の間 | 1 秒 | 0〜15 秒 |

スライダーで調整可。

### 通常読み上げとの違い

| | 通常読み上げ | 司会モード |
|-|-----------|---------|
| utterance 数 | 1 | セクションごとに別 |
| 間の挿入 | なし | あり |
| 話速変更の反映 | 次回起動から | 次のセクションから |
| 「次へ」スキップ | なし | あり |

### 実際に読まれる全文を確認したい

セクション一覧の下にある「**実際に読み上げられる全文プレビュー**」をクリックで展開。辞書置換・句読点正規化まで適用された **最終形** がセクション単位で表示されます。セクション一覧（目次）は原稿に近い形のまま残るので、原稿確認はそちら、発声確認はプレビュー、と使い分けられます。

## 9. 朝会での実践フロー

ここまでの機能を組み合わせて、毎朝の朝会で実際に使う流れです。

### 事前準備（初回 + メンバー入れ替え時のみ）

1. 「メンバー」ページで参加メンバーを一括登録
2. 自分の行に「自分」フラグを立てる
3. 辞書ページで社内略語などを登録

### テンプレ作成（初回のみ）

`/reader` のテキストエリアに以下のような台本を作って「現在を保存」：

```
# オープニング
おはようございます。{date} {weekday} の朝会を始めます。
本日の朝会登板は、 {presenter} AIエージェントが行います。

# 本日の勤怠確認
本日の予定は、

{本日の予定}

# 明日の勤怠確認
明日の予定は、

{明日の予定}

# 連絡事項
連絡事項がある方はいますか？

# クロージング
本日もよろしくお願いします。
```

名前: `朝会` などで保存。

### 毎朝の運用

1. ブラウザで http://localhost:3000/reader を開く
2. 「保存した台本」プルダウンで `朝会` を選択 → 内容が展開される
3. 別タブの Copilot で本日の予定を要約 → 出力をコピー
4. プレースホルダパネルの `{本日の予定}` 欄に貼り付け
5. 同じく明日分を `{明日の予定}` に貼る
6. `{presenter}` で本日の登板者を選択
7. `{date}` `{weekday}` は自動入力済みなのでそのまま
8. 「**司会モードで再生**」をクリック
9. 朝会開始 — bot が順に進行、間で参加者が話す
10. 終了

### Copilot プロンプト案

```
本日の予定を読み上げ用にまとめてください。
- マークダウンの太字（**）や箇条書き（-）は使わない
- カテゴリ名は単独行で書き、コロンを使わない
- 各カテゴリの間は空行 1 行
- 前置きや締めのあいさつは不要
```

出力例：
```
在宅勤務
水口、浅川

外出
富士見外出 神澤
広丘外出 小国、鈴木
```

そのまま `{本日の予定}` に貼ると、セクション分けされてメンバー敬称も付与されます。

### チャットを整形ボタン

チャット出力（Copilot / ChatGPT 等）に `**太字**` や `## 見出し` が紛れたら、textarea ラベル右の「**チャットを整形**」ボタンを使えば 1 クリックで正規化されます。メイン textarea と各 textarea プレースホルダの両方にボタンがあります。

## 10. 困ったとき（トラブルシューティング）

### 「このブラウザは Web Speech API に対応していません」と出る

→ Edge / Chrome の最新版で開く。Safari や古いブラウザは未対応。

### 声のプルダウンが空、または英語の声しか出ない

→ Edge を使う、または Windows の「設定 → 時刻と言語 → 音声」で日本語音声パックをインストール。

### 「アスタリスク」「カッコ閉じる」と読まれる

→ textarea ラベル右の「チャットを整形」ボタンを押す。または手動で `**` `（）` を削除。

### 名前にさんが付かない

→ メンバー登録されていないか、「自分」フラグが立っている可能性。`/reader/members` で確認。

### 名前が読み間違える（漢字のまま読まれる）

→ メンバーに「よみがな」を登録（カタカナ／ひらがなで）。

### 司会モードのセクションが認識されない

→ 見出しは `# タイトル`（半角 # のあとに半角または全角スペース、その後タイトル）。全角 `＃` でも可。`### ` などは「チャットを整形」で `# ` に統一可能。

### 話速を変えても変わらない

→ 通常読み上げ中は変えても反映されません。一度止めて押し直し。司会モードならセクション切り替えで反映。

### F5 で辞書やテンプレが消えた

→ localStorage は通常 F5 では消えません。「サイトデータを削除」「キャッシュクリア」「シークレットモード」のどれかで消えた可能性。シークレットモードは終了で全消去なので使わないこと。

### 別 PC / 別ブラウザで開いたら何もなかった

→ localStorage は **保存したブラウザだけ** にあります。デバイス間共有機能は未実装。Phase 2 で JSON エクスポート / インポートを追加検討。

### 長い文章の途中で止まる

→ Web Speech API の既知問題（OS 依存）。文章を `# 見出し` で複数セクションに分けて司会モードで読むと回避できます（utterance が短くなるため）。

## 補足：データはどこにある？

すべてブラウザの **localStorage** に JSON で保存されています。

| キー | 内容 |
|-----|------|
| `voice-reader.dictionary` | 辞書 |
| `voice-reader.members` | メンバー名簿 |
| `voice-reader.templates` | 台本テンプレ |

確認方法：

1. ブラウザで F12 → 「Application」（または「アプリケーション」）タブ
2. 左サイドバー → Storage → Local Storage → http://localhost:3000
3. 各キーをクリックすると右に JSON が表示される

直接編集すれば一括書き換えも可能（壊しても辞書/メンバー/テンプレが消えるだけなので安全）。

## 補足：バックアップ・別 PC への移行

辞書・メンバー・テンプレの各画面に **「エクスポート」** ボタンと **「インポート」** ボタンがあります。3 ファイル（`voice-reader-dictionary-*.json` / `voice-reader-members-*.json` / `voice-reader-templates-*.json`）をまとめて持ち運べば、別 PC や別ブラウザに完全に引き継げます。

定期的なバックアップ運用：
- 月 1 回程度、3 ファイルをエクスポートしてクラウドストレージなどに保管
- 新 PC セットアップ時はこれをインポートするだけで復元完了
